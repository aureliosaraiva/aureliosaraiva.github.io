Primeiro post do blog. A ideia aqui é simples: um espaço para registrar
aprendizados sobre engenharia de software, arquitetura e IA aplicada ao
desenvolvimento.

## Como este site funciona

O site é estático e publicado pelo **GitHub Pages** com Jekyll. Cada post é
um arquivo Markdown na pasta `_posts`:

```bash
_posts/2026-10-04-ola-mundo.md
```

O cabeçalho de cada arquivo define o título e as tags:

```yaml
---
title: "Olá, mundo"
tags: [meta]
---
```

Sem frameworks de CSS e sem JavaScript, só HTML, CSS e texto.

> Fazer simples é difícil. Mas vale a pena.
